
DATA SCIENCE PROJECT DATASETS (Batch 2)

PROJECT 1: Employee Salary Prediction
Dataset: employee_salary_prediction.csv
Model: Linear Regression
Target Variable: salary

Features:
- years_experience: Number of years of work experience
- education_level: Education qualification (Bachelors, Masters, PhD)
- skill_score: Skill assessment score (40–100)
- certifications: Number of professional certifications


PROJECT 2: Customer Purchase Prediction
Dataset: customer_purchase_prediction.csv
Model: Logistic Regression
Target Variable: purchased (Yes/No)

Features:
- age: Customer age
- income: Annual income
- website_visits: Number of visits to the website
- previous_purchases: Number of previous purchases


PROJECT 3: Student Admission Prediction
Dataset: student_admission_prediction.csv
Model: Logistic Regression
Target Variable: admitted (Yes/No)

Features:
- gpa: Student GPA
- entrance_exam_score: Entrance exam score
- interview_score: Interview evaluation score
- extracurricular_score: Score based on extracurricular activities

NOTE:
These datasets are simulated for educational purposes and were not downloaded from the internet.
